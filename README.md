# Monorepo app fixture

A test fixture for Orbitr (EVAL-01c, https://github.com/asquitt/orbitr/issues/1444). A repository with two apps; the Next.js marketing app in `apps/marketing` (static export to `apps/marketing/out`) is built by a Git-connected Cloudflare Pages project with root directory `apps/marketing`. Seeded from the legacy `nextjs-monorepo` discovery fixture. Contains no real business data.
